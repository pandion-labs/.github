# Pandion Labs

Developer tools for running software projects with AI coding agents under human direction.

## Fishhawk

The governed, auditable workflow for agent-driven software development.

Fishhawk lets one developer run a repository the way a team would. You set direction and decide how much the crew of agents may decide on its own. The agents plan, implement and review changes through stages you define. Approval gates put the decisions that belong to a human in front of a human. Every plan, change and approval lands in a signed, append-only audit log, so the record shows afterward what was done, why, and by whose decision.

Fishhawk orchestrates coding agents; it is not one. It runs on your CI, keeps your issue tracker as the source of truth, and develops itself through its own workflow.

## The name

*Pandion* is the genus of the osprey, the bird the American South calls a fishhawk.
